# Player-Movement-with-stamina
this project uses unity's new input system with character controller component, with an additional stamina system,
 to use the stamina system you need to do this :
 create an image and set it's visibility/alpha to 0 and make it fit the entire screen and add a canvas group component to it
 then create two images children, one called stamina bar and set it's color to white and position it wherever you want
 the other named stamina_bar_BG and set it's color to black and that's it and put it behind the main stamina bar, copy the code, make your action map and actions
 and drag the components needed in both scripts !! note that both scripts of PlayerMoveAndJump and staminaBar need to be in the player component !! and the MouseLook would be  in the camera
